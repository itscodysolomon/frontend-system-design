Answer checklist

Use this structure every time.

  1. Clarify: users, platforms, core flows, scale, constraints.
  2. Model: routes, components, state, API contracts, data lifecycle.
  3. Optimize: loading, rendering, caching, bundling, perceived speed.
  4. Harden: loading/error/empty/offline states, security, accessibility.
  5. Scale the team: design system, tests, ownership, observability.
  6. Trade off: explain what you chose, what you rejected, and why.
