Answer framework

Use this in interviews

  1. Clarify requirements: users, devices, core flows, constraints.
  2. Sketch architecture: pages, components, data layer, APIs, state.
  3. Discuss performance: loading strategy, rendering, caching, bundle size.
  4. Cover edge cases: errors, empty states, offline, permissions, slow networks.
  5. Explain tradeoffs: why this approach over alternatives.
